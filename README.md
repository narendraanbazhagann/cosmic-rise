🌌 Cosmic Rise

Cosmic Rise is a space-themed tap-to-earn web game designed as a Telegram Mini App.
Players tap a central cosmic object to earn resources, upgrade cards, and generate passive income over time.

This project focuses on simple but addictive gameplay mechanics combined with a clean, futuristic UI.

🚀 Project Vision

Cosmic Rise aims to deliver:

Easy onboarding

Short, addictive play sessions

Long-term progression through upgrades

Strong community growth via referrals and events

The game is designed to scale gradually while testing user retention and engagement.

🎮 Core Gameplay Mechanics
🟡 Tap System

Players tap a central Sun to earn Cosmo Coins

Each tap increases total balance

Tap power can be upgraded

🃏 Upgrade Cards

Cards increase:

Profit per hour

Tap efficiency

Passive income

Cards can be upgraded in levels

Future plan: rarity system (Common, Rare, Epic)

⏱ Profit Per Hour

Players earn coins passively

Earnings continue even when offline

Total profit depends on owned and upgraded cards
